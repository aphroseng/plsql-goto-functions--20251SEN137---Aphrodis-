## 📋 Assignment Structure & Files

### 00_setup/
* `create_tables.sql` - Sets up departments and employees tables with sample data.

### 01_goto/
* `A1_number_classifier.sql` - Classifies positive, negative, or zero numbers using `GOTO`.
* `A2_salary_review.sql` - Routes salary review brackets using `GOTO`.
* `A3_illegal_goto.sql` - Demonstrates control flow avoiding illegal jumps.
* `A4_rewrite_no_goto.sql` - Clean structural rewrite using `IF-ELSIF` instead of `GOTO`.

### 02_functions/
* `B1_fn_annual_salary.sql` - Computes annual salary including commission (`NVL`).
* `B2_fn_years_of_service.sql` - Calculates years of service via `MONTHS_BETWEEN`.
* `B3_fn_calculate_tax.sql` - Computes income tax based on tiered brackets.
* `B4_fn_dept_name.sql` - Retrieves department name by ID with exception handling.
* `C1_fn_validate_payroll.sql` - Combined task to validate employee payroll details.
